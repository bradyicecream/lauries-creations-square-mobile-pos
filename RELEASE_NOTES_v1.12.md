# Laurie’s Creations POS v1.12 — Selected Square Item Import (Sandbox)

- Adds **Import Square item** under **Products & modifiers** in the local Android register.
- After private sign-in, open the live catalog comparison page and tap **Use Square** for an individual Square product to download a JSON transfer file.
- Transfer that file to the Android device; choose **Import Square item**, review the price, variations and modifier counts, and confirm.
- Only the selected product is added or updated. Existing cart lines, favorites, flavors, operations records, and other products remain unchanged.
- Square stays read-only. No Square catalog write or production payment capability is enabled.
- Unknown prices remain flagged for review rather than guessed. Square data is verified for the configured mobile location.
- Explicit Android document selection replaces the previously unavailable native file chooser in the embedded register.

The register remains **SANDBOX TEST PAYMENTS ONLY**. Export a full register backup before installing updates or importing products. The browser page and installed app do not sync automatically.
