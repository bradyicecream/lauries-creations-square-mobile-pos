# Laurie’s Creations POS v1.9.0 — Square-Inspired Editable Register Grid

Android Sandbox test APK, independently branded for Laurie’s Creations.

## Register layout
- Familiar two-part, square checkout tile grid: colored top tile, label and price below.
- Blank tile spaces and **Edit grid** directly above Favorites.
- Choose a tile to select a color, move left/right or remove it from the current Favorites page; removing a tile never deletes the product in the Item Library.
- Add individual item tiles, category shortcuts and a Custom Amount shortcut from any empty grid square.
- Custom Favorites pages, tab creation/renaming/reordering, and the optional visibility toggles for the Keypad and Library remain.
- A full-row, searchable Item Library and edge-to-edge manual amount Keypad.
- Checkout, Transactions and More at the bottom on the Zebra TC21 handheld and ET51 tablet.
- The current sale is still visible on larger screens, with responsive bottom-drawer access on handhelds.

All prior product variations, reusable modifiers, cart quantity controls, staff, inventory, cash management, loyalty preview, Square Sandbox card tests, no local sales tax, and card-only mandatory Gratuity settings remain.

**Limitations:** This is not a reskin of the official Square Point of Sale APK or a live Square catalog connection; the grid is saved on the device (and in JSON register backups). No production payments, Banking sync, live Square Loyalty or second-device customer display sync. Square brand marks and official UI assets have not been copied. Mandatory card-only Gratuity may be subject to regulated card surcharge rules.

Back up device-local register data before installing over an earlier debug-signed APK.
